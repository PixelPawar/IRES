# IRES

An intelligent desktop voice assistant built with Python.

IRES understands natural language commands, launches applications, opens websites, searches Google, answers AI queries, and is designed with a modular architecture for future expansion.

---

## Features

- Voice Recognition
- Text-to-Speech
- AI Chat
- Smart Application Launcher
- Google Search
- Website Launcher
- Modular Architecture
- Fuzzy Matching

---

## Tech Stack

- Python
- SpeechRecognition
- pyttsx3
- OpenAI API
- dotenv
